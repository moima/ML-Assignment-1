# ML-Assignment-1

This repository contains my solutions for ML Assignment 1, focusing on regression models and neuronal response analysis. The assignment explores polynomial regression, Gaussian nonlinear regression, and the von Mises model to fit and compare orientation tuning curves using neural spike data. Model performance is evaluated using mean squared error (MSE), with a focus on goodness of fit, model complexity, and the importance of accounting for circular orientation.
